# GAWAD KALASAG 2025  
## Compliance Document Tracker System

## 📌 Overview

The **Gawad Kalasag 2025 Compliance Document Tracker** is a **web-based, offline-capable tracking system** designed to assist Local Government Units (LGUs) in monitoring and managing compliance with the **Gawad Kalasag Seal of Excellence for Disaster Risk Reduction and Management (DRRM)**.

It consolidates all **Indicators, Measures of Verification (MOVs), timelines, assignments, and progress monitoring** into a single interactive dashboard with built-in reporting and export features.

---

## 🎯 Purpose

This system aims to:

- Track completion of **Gawad Kalasag indicators and MOVs**
- Monitor **overall and per-category compliance progress**
- Assign **focal persons** for each MOV
- Manage **implementation timelines** using a Gantt-style schedule
- Generate **print-ready and PDF-ready reports**
- Replace manual spreadsheets and paper-based tracking

---

## 🧩 Scope and Coverage

The tracker covers the following **six (6) Gawad Kalasag Areas**:

1. **Structure**
2. **Competency**
3. **Management System**
4. **Enabling Policies**
5. **Knowledge Management and Advocacy**
6. **Partnership and Participation**

Each area includes:
- Indicators
- Sub-indicators
- Detailed Means of Verification (MOVs)

---

## 🖥️ Key Features

### 📊 Progress Monitoring
- Overall compliance percentage
- Per-category progress bars
- Automatic updates when MOVs are marked as completed

### ✅ MOV Checklist
Each MOV includes:
- Completion checkbox
- Timeline (start and end dates)
- Assigned focal person
- Remarks / observations

### 🗓️ Gantt Timeline View
- Weekly planning view (January–May)
- Automatically highlights active weeks
- Toggle ON/OFF for simplified viewing and printing

### 💾 Offline Data Saving
- Uses **browser LocalStorage**
- No backend or internet connection required after loading
- Manual **Save All** function

### 📄 Export & Printing
- Browser print support (print-optimized layout)
- PDF generation using `html2pdf.js`
- Landscape format with preserved colors and layout

---

## 🚀 How to Use

1. Open the `.html` file in a web browser
2. Review categories, indicators, and MOVs
3. Check the **Done** box when a MOV is completed
4. Assign timeline and focal person
5. Add remarks if needed
6. Click **Save All** to store progress
7. Use **Export** to print or generate a PDF

---

## 🖨️ Print & PDF Notes

- Optimized for **landscape orientation**
- Gantt bars and progress indicators are preserved
- Page breaks avoid splitting indicators
- Colors are retained in print and PDF output

---

## ⚠️ Important Notes

- Data is saved **per browser and per device**
- Clearing browser cache or LocalStorage will erase saved data
- No automatic cloud backup is included
- Intended as a **tracking and documentation aid only**
